# Hotel Management RESTful API

Тестовое задание на разработку RESTful API приложения для работы со списком отелей. 

## Используемые технологии
* **Java 21** (согласно требованиям ТЗ)
* **Spring Boot 3.2+** (Web, Data JPA)
* **H2 Database** (In-memory database)
* **Liquibase** (Миграции базы данных)
* **Maven** (Сборка проекта)
* **Swagger / OpenAPI 3** (Автоматическая документация API)

## Основные возможности
Реализованы следующие методы (prefix: `/property-view`):
1. `GET /hotels` — получение краткой информации о всех отелях.
2. `GET /hotels/{id}` — получение полной информации по конкретному отелю (адрес и контакты возвращаются в виде объектов).
3. `GET /search` — гибкий поиск по параметрам: `name`, `brand`, `city`, `country`, `amenities`.
4. `POST /hotels` — создание нового отеля.
5. `POST /hotels/{id}/amenities` — массовое добавление списка удобств к отелю.
6. `GET /histogram/{param}` — получение статистики (группировка) по параметрам: `brand`, `city`, `country`, `amenities`.

## Особенности реализации
* **Слоистая архитектура**: Проект разделен на слои: Controller, Service, Repository, Entity, DTO.
* **DTO паттерн**: Для разных методов API используются разные структуры объектов (Short и Full версии), чтобы оптимизировать передачу данных.
* **Liquibase**: Структура таблиц `hotel` и `hotel_amenities` создается автоматически при запуске приложения.
* **Swagger UI**: Для удобного тестирования методов API подключена документация.
